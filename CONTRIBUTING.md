# Изменения Terminal Face

В проекте два Android product flavors, а не два форка. Не меняйте идентификатор
выпущенного приложения ради визуальных изменений. Общие шрифты и ресурсы находятся
в `watchface/src/main/`, раздельные переопределения — в `src/compact/` и `src/large/`.

Перед отправкой изменений:

```sh
sh tools/check.sh
python3 tools/test_large_type_sketches.py
python3 tools/test_familiar_refinement.py
python3 tools/test_typography_hierarchy.py
python3 tools/check_publication.py
```

`tools/prepare_variants.py` воспроизводит исходные flavor overlays из сохранённых
дизайнов. Если намеренно меняете оформление, измените генератор и соответствующие
тесты, а не архивный WFF. `tools/build_large_type.py` воспроизводит одобренный Large.
`tools/rebuild_assets.py` обновляет текущие общие шрифты/превью; убедитесь, что
изменения общих ресурсов подходят обоим приложениям. Не применяйте такой генератор
к старым архивам, чтобы получить новые контрольные суммы задним числом.

Ресурсные WFF-пакеты не должны содержать Kotlin/Java-код или DEX. Не добавляйте
новые разрешения, собственные поставщики, сетевую загрузку или production-подпись
без отдельного обсуждения. Изменения размера/геометрии проверяйте на круглом экране,
в active и ambient, с длинными значениями и разными шрифтами.

Для выпуска обновить метаданные в `watchface/variants.properties`, выполнить полную
проверку, затем `python3 tools/archive_version.py`. Архивы неизменяемые; повторная
запись другой сборкой отклоняется. Коммит должен содержать исходники и новые
архивы. Создать теги `vVERSION` для обоих архивируемых вариантов; если меняется
только один вариант, выбрать его через `--flavor` и не перезаписывать второй.

Не добавлять секреты, приватные ключи, личные данные устройства или локальные пути.
Код проекта — MIT, сторонние шрифты и материалы сохраняют собственные лицензии.
