# Проверка прототипов и сравнительной сборки 0.4.0-test

Дата: 2026-10-13. Ветка: `feat/terminal-face`. Основа: `931c71e`.

## Инструменты

- OpenJDK 21.0.12.1, Gradle 9.6.0, Android Gradle Plugin 9.4.0.
- SDK Platform 37.0 revision 2, Build-Tools 36.0.0.
- Официальный Google WFF Validator 1.7.0, проверка схемы версии 2.
- Официальный Memory Footprint Evaluator, выпуск 2026-09-08.
- Контрольные суммы инструментов зафиксированы в `tools/setup_validation.sh`.

## Автоматические проверки

`sh tools/check.sh` выполнен успешно:

- WFF XML соответствует спецификации версии 2.
- Debug APK и release AAB собираются.
- APK не содержит DEX-файлов; AAB проходит встроенное ограничение resource-only.
- Android lint завершён без ошибок. Есть предупреждения о новой версии Gradle и
  ресурсах, которые стандартный unused-resource анализатор не видит в raw WFF XML.
- Memory Footprint Evaluator возвращает PASS.

Оценка памяти AAB 0.1.0 с консервативным greedy-перебором конфигураций:

| Показатель | Байты |
|---|---:|
| Ресурсы | 54 756 |
| Максимум active | 54 756 |
| Максимум ambient | 1 647 736 |

Оба режима укладываются в официальные пределы 100 МБ active и 10 МБ ambient.
Это расчёт инструментом Google, а не измерение потребления батареи на физических часах.

## Wear OS API 34

Использован существующий эмулятор `metar_wear_api34`, экран 384×384,
`ro.build.version.sdk=34`. Пакет: `dev.int0x19.watchface.terminal`.

- APK устанавливается и выбирается через системный WFF runtime.
- Видны время, дата, UTC-смещение и таблица с пустыми значениями `--`.
- Системные поставщики шагов и пульса передают данные в выбранные слоты.
- После исправления сравнения BooleanConfiguration видны секунды.
- В 12-часовом режиме отображается AM/PM.
- Системный редактор открывается; доступны настройки подписей, палитры и даты.
- На странице complications отображаются все восемь независимых активных зон
  выбора источника, что подтверждено UI-иерархией и [скриншотом редактора](api34-editor.png).
- Для первой ячейки открывается системный [список поставщиков](api34-provider.png).
- Изменение подписи сохраняется при переустановке APK с тем же ключом.
- После обновления APK циферблат при необходимости повторно активируется через
  `DEBUG_SURFACE`; этот шаг включён в ручной сценарий установки.
- Финальный проход выполнен после чистой переустановки нового тестового пакета;
  внесённые во время проверки подписи и настройки на эмуляторе сброшены.

Скриншот фактического установленного циферблата: [api34-active.png](api34-active.png).
Данные системных поставщиков в эмуляторе не являются измерениями здоровья пользователя.

## Итерация 0.2.0: UTC, батарея, шрифт и настройки

Дата: 2026-10-13. APK обновлён поверх 0.1.0 без очистки данных;
выбранные ранее ручные подписи и поставщики сохранены.

- `sh tools/check.sh`: четыре регрессионных теста ресурсов, WFF 2 Validator,
  debug APK, release AAB, отсутствие DEX, Android lint и Memory Footprint — PASS.
- Проверены неизменные координаты четырёх верхних строк, живые источники
  UTC / местного смещения / батареи и наличие всех восьми настраиваемых слотов.
- Для всех вариантов подписей и даты есть читаемые PNG-миниатюры, включённые в APK.
  Сам текст циферблата — TTF, не изображения; проверены равные ширины символов,
  латиница, кириллица, степень и тире, размещение коротких подписей в исходной сетке.
- По умолчанию все подписи AUTO; старые настройки не переопределяются обновлением.
- AUTO выбран через штатный редактор эмулятора для правой строки 3 (пульс)
  и правой строки 4 (пустой источник). Пульс передал свой заголовок BPM, который
  заменил ручную подпись HR; у пустого источника вместо неподходящей подписи WIND
  показано `—`. [Фактический экран с AUTO](api34-v2-auto.png).
  Ветка со значком при отсутствии заголовка проверена по схеме и тестами XML;
  проход с реальным поставщиком без заголовка остаётся в матрице поставщиков.
- Фактическая батарея эмулятора `dumpsys battery`: 100 / 100;
  на циферблате отображается BATT / 100%, а не демонстрационное 96%.
- `tools/check_emulator_timezones.py` временно сменил пояс тестового эмулятора,
  сделал скриншоты и восстановил `Asia/Tashkent` в блоке `finally`.
  Ни данные приложений, ни выбор поставщиков не сбрасывались.
- Повторная генерация Mono TTF, пиксельного TTF, превью и миниатюры AUTO даёт
  идентичные SHA-256 (Pillow 11.1.0, fontTools 4.57.0).

формату эмулятора; UTC остаётся 24-часовым. Числа в таблице — время теста,

## Итерация 0.3.0: короткие подписи и новая компоновка

Дата: 2026-10-13. Восемь тестов разметки, WFF 2 Validator, сборка APK/AAB,
Android lint, проверка отсутствия DEX и Memory Footprint — PASS.

- Во всех восьми ячейках одинаковые 28 ручных вариантов до четырёх символов.
  Проверены уникальность, длина, шрифтовая ширина и английские/русские расшифровки.
- AUTO и NONE сохранены. Старые ID HI/LO, STEPS и EVENT сохранены, их текст
  сокращается до H/L, STEP и EVNT во всех пяти типах данных каждого слота.
- Шапка UTC / BATT поднята на y=48/73, дата во всех трёх стилях — на y=108.
  Нет текста на прежнем y=224; крупные часы и нижние ячейки не перемещены.
- Шрифт мелкого текста 24 → 26, длинных значений 20 → 22, AM/PM 18 → 20.
  Для LONG_TEXT letterSpacing=-0.04: строка NE 3.1 M/S помещается без потери единиц.
- APK обновлён на API 34 без очистки данных. H/L и STEP отображаются для
  ранее выбранных старых ID; источник пульса продолжает отдавать данные.
- Через штатный редактор выбрана NTFY в правой строке 4. Подтверждено её
  отображение на циферблате; источник ячейки остался EMPTY и показывал `--`.
  Число уведомлений этим тестом не измерялось. Затем исходный AUTO восстановлен.
- [Экран с NTFY](api34-v3-ntfy.png), [редактор](api34-v3-ntfy-editor.png),
  [финальный экран](api34-v3-active.png). Выбранные источники не менялись.
- Память AAB: ресурсы / maxActive 91 164 байта, maxAmbient 1 684 144 байта — PASS.
- Архиватор имеет отдельные тесты: повторное сохранение неизменной версии
  не пишет файлы, другая сборка и повреждённый архив отвергаются.

## Сравнительная сборка 0.4.0-test — A/B/C

- `sh tools/check.sh`: 9 тестов разметки и 2 теста архива, WFF 2 Validator,
  APK/AAB, отсутствие DEX, Android lint и Memory Footprint — PASS.
- В одном пакете три варианта с отдельными миниатюрами. Сохранены восемь
  slotId, прежние типы данных и политики поставщиков; зоны выбора не пересекаются,
  центры подписей и значений находятся в зоне своего слота во всех вариантах.
- Генератор воспроизводим из неизменяемой 0.3.0. SHA-256 её архива проверены.
- Пустые слоты сохраняют `--`, AUTO/NONE и ручные подписи работают по той же
  декларативной схеме. Для нижнего ряда добавлен меньший шрифт длинного SHORT_TEXT.
- Превью A/B/C и ambient содержат иллюстративные данные, не результаты запуска на часах.
- Память: ресурсы / maxActive 124 860 байт, maxAmbient 4 924 144 байта — PASS.
- Батарея A/C использует PNG с прозрачностью: первоначальный vector XML не был
  распознан инструментом памяти; после замены PNG включён в APK/AAB и проверка прошла.
- Попытка запуска существующего `metar_wear_api34` остановилась на проверке
  свободного места. На разделе /home около 1.6 ГБ; данные AVD не очищались.
  Переключение A/B/C в реальном системном редакторе, установка этой сборки и
  клики по поставщикам на устройстве пока не подтверждены.
