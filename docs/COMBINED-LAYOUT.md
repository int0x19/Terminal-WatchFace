# Совмещённая разметка — 0.7.0-test

Шапка и часы сохранены из одобренной 0.5.0-test. После пользовательского теста
дата увеличена и два нижних поля заменены одним широким — пользователь уточнил,
что нужен один источник, а не два показателя в общей строке.
Предыдущие версии, включая A/B/C из 0.4.0-test, сохранены отдельно.
В 0.7.0-test добавлены [настройки оформления и языка даты](TYPOGRAPHY.md).
Шапка UTC/BATT и значения показателей от этих настроек не зависят.

Шапка:

```text
  09:34     BATT
  UTC+5      96%
```

Содержимое строк центрировано внутри двух колонок; их центры симметричны
относительно центра экрана. Первая строка слева — живое время UTC без суффикса,
вторая — местное системное смещение с учётом DST. Это не определение по GPS.
Справа реальные данные батареи; нижний слот для неё не используется.

После шапки — дата, затем крупное HH:MM. Размер шрифта часов 100, области
302×96 с центром x=225. Двоеточие — третий из пяти одинаковых символов;
контуры всех цифр и двоеточия отдельно центрированы в ячейках 0.6 em.
Исправлены боковые поля узких символов, особенно «1» и «:».
Секунды и AM/PM находятся отдельно справа и не влияют на центрирование HH:MM.

Дата во всех трёх стилях увеличена с 28 до 36 (+28.6%). Область x=30, y=112,
390×44 сохраняет центр строки и помещает полную дату с каждым английским месяцем,
включая SEPTEMBER. Крупные часы и шапка не перемещены.

Нижняя таблица: две колонки по три строки с прежним шагом 36, затем одно широкое
поле с центром x=225. Подписи верхних ячеек — 30, короткие значения — 32.
Область текста общей нижней строки x=82, y=362, 286×36. Подпись и значение
составляют один PartText: CENTER применяется ко всей строке независимо от длины
источника или подписи. Зелёный заголовок, янтарное значение, AUTO / NONE и ручные
подписи сохранены. Размер 32 (LONG_TEXT 30); слишком длинные строки сокращаются.
Размеры даны в координатах WFF 450×450.

Реализация использует несколько цветных Font внутри Text и InlineImage для
значка поставщика в AUTO. См. официальные описания
[Text](https://developer.android.com/reference/wear-os/wff/group/part/text/text),
[Font](https://developer.android.com/reference/wear-os/wff/group/part/text/font) и
[InlineImage](https://developer.android.com/reference/wear-os/wff/group/part/text/formatter/inline-image).
Схема проверена именно как WFF 2, а не только по текущей справке WFF 5.

## Выбор шрифта

Удержать циферблат → редактирование → «Шрифт часов»:

- Блочный (по умолчанию).
- Точечный.
- Контурный.

Все три — настоящие встроенные моноширинные TTF, не изображения цифр.
Миниатюры редактора содержат пример «12:34» соответствующим шрифтом.
Параметр влияет на крупные часы в активном режиме. Мелкий текст остаётся
читаемым Terminal Mono, а в ambient часы всегда точечные; таблица и секунды скрыты.

Превью: [блочный](font-block.png), [точечный](font-dot.png),
[контурный](font-mono.png), [сравнение](font-comparison.png).
Все показания в этих изображениях иллюстративные. Локальный рендерер не заменяет
проверку системного WFF runtime на часах.

## Проверка на часах

1. Установить APK поверх текущего с тем же ключом, без удаления приложения.
2. Проверить сохранение выбранных поставщиков, коротких подписей и палитры.
3. В разделе «Шрифт часов» сравнить все варианты, особенно время 11:11 и 23:59.
4. Проверить секунды, формат 12/24 часа и AM/PM, батарею 100%, дробный пояс.
5. Нажать на каждый из семи показателей, особенно на центр общей нижней строки.
6. Сравнить нижнюю строку с подписью AUTO, ручной ALRM и NONE; проверить длинные
   значения и разные палитры. Проверить полную дату в сентябре и ambient.

Старая настройка A/B/C больше не отображается. Общая нижняя строка сохраняет
slotId=4 и label4 — прежние нижние левые данные (ALRM на пользовательском снимке).
Нижний правый slotId=8 и label8 удалены по запросу. Для оставшихся семи источников
идентификаторы, типы и политики сохранены; шрифт, палитра, дата и секунды также.
Сохранение при обновлении проверено по ресурсам; новый APK на устройстве ещё
не протестирован. Источник и подпись общей строки можно сменить в редакторе.

## Воспроизведение

```sh
python3 tools/build_layout.py --output /tmp/terminal-combined.xml
# Сравнить и применить XML к ресурсу watchface.xml.
python3 tools/rebuild_assets.py
sh tools/check.sh
python3 tools/archive_version.py
```

Архив содержит APK, AAB, WFF, active/ambient-превью для всех шрифтов, сравнение
и контрольные суммы. Полные исходники зафиксированы тегом `v0.7.0-test`.
