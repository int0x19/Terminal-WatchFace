# Совмещённая разметка — 0.5.0-test

Компоновка перенесена из одобренного пользователем превью без изменения его
геометрии. Это новая тестовая сборка; предыдущие A/B/C сохранены в 0.4.0-test.

Шапка:

```text
  09:34     BATT
  UTC+5      96%
```

Содержимое строк центрировано внутри двух колонок; их центры симметричны
относительно центра экрана. Первая строка слева — живое время UTC без суффикса,
вторая — местное системное смещение с учётом DST. Это не определение по GPS.
Справа реальные данные батареи; нижний слот для неё не используется.

После шапки — дата, затем крупное HH:MM. Размер шрифта часов 100, области
302×96 с центром x=225. Двоеточие — третий из пяти одинаковых символов;
контуры всех цифр и двоеточия отдельно центрированы в ячейках 0.6 em.
Исправлены боковые поля узких символов, особенно «1» и «:».
Секунды и AM/PM находятся отдельно справа и не влияют на центрирование HH:MM.

Визуальные отступы вокруг часов увеличены примерно в 1.5 раза относительно
варианта A предыдущей сборки. Нижняя таблица сохраняет строчное расположение A;
шаг строк уменьшен с 48 до 36. Подписи — 30, короткие значения — 32, длинные
меньше, чтобы сохранить единицы. Размеры даны в координатах WFF 450×450.

## Выбор шрифта

Удержать циферблат → редактирование → «Шрифт часов»:

- Блочный (по умолчанию).
- Точечный.
- Контурный.

Все три — настоящие встроенные моноширинные TTF, не изображения цифр.
Миниатюры редактора содержат пример «12:34» соответствующим шрифтом.
Параметр влияет на крупные часы в активном режиме. Мелкий текст остаётся
читаемым Terminal Mono, а в ambient часы всегда точечные; таблица и секунды скрыты.

Превью: [блочный](font-block.png), [точечный](font-dot.png),
[контурный](font-mono.png), [сравнение](font-comparison.png).
Все показания в этих изображениях иллюстративные. Локальный рендерер не заменяет
проверку системного WFF runtime на часах.

## Проверка на часах

1. Установить APK поверх текущего с тем же ключом, без удаления приложения.
2. Проверить сохранение выбранных поставщиков, коротких подписей и палитры.
3. В разделе «Шрифт часов» сравнить все варианты, особенно время 11:11 и 23:59.
4. Проверить секунды, формат 12/24 часа и AM/PM, батарею 100%, дробный пояс.
5. Нажать на каждый из восьми нижних показателей, проверить ambient и нижние углы круга.

Старая настройка A/B/C больше не отображается: новая сборка использует одну
согласованную геометрию. slotId, типы данных, политики поставщиков, идентификаторы
подписей, палитры, даты и секунд остались прежними. Сохранение при обновлении
проверено по ресурсам; новый APK на устройстве ещё не протестирован.

## Воспроизведение

```sh
python3 tools/build_layout.py --output /tmp/terminal-combined.xml
# Сравнить и применить XML к ресурсу watchface.xml.
python3 tools/rebuild_assets.py
sh tools/check.sh
python3 tools/archive_version.py
```

Архив содержит APK, AAB, WFF, active/ambient-превью для всех шрифтов, сравнение
и контрольные суммы. Полные исходники зафиксированы тегом `v0.5.0-test`.
