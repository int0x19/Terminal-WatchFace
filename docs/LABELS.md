# Короткие подписи

Этот каталог относится к сохранённым версиям до 0.6.1-rollback включительно.
Начиная с 0.6.2-fixed-labels-test ручной выбор удалён, все подписи работают в AUTO.
Этот вариант принят пользователем как основа текущей ветки циферблата:
[описание эксперимента](FIXED-LABELS-TEST.md).

Каждое из семи полей (до 0.6.0-test — восемь ячеек) имеет одинаковый набор:
28 ручных подписей длиной
не более четырёх символов, AUTO и NONE (без подписи). Латиница сохраняет
терминальный стиль; в русскоязычном редакторе есть русские расшифровки.

| Подпись | Значение |
|---|---|
| HR / BPM | Пульс |
| NTFY | Непрочитанные уведомления |
| STEP | Шаги |
| CAL | Калории |
| DIST | Дистанция |
| GOAL | Цель активности |
| ACTV | Минуты активности |
| FLRS | Пройденные этажи |
| SPO2 | Кислород в крови |
| SLEP | Сон |
| STRS | Стресс |
| BATT | Заряд батареи |
| TEMP | Температура |
| H/L | Максимум / минимум температуры |
| WIND | Ветер |
| HUM | Влажность |
| PRES | Атмосферное давление |
| UV | УФ-индекс |
| COMP | Компас |
| ALT | Высота |
| DATE | Дата |
| DOW | День недели |
| EVNT | Ближайшее событие календаря |
| ALRM | Ближайший будильник |
| SUN | Восход / закат |
| UTC | Мировое время |
| DATA | Нейтральная подпись данных |

Сначала выбрать источник данных ячейки, затем соответствующую подпись.
Ручная подпись не переключает источник, не меняет единицы и не запускает сенсор.
Например, выбор SPO2 сам по себе не добавляет измерения кислорода.

Пульс, шаги, непрочитанные уведомления и батарея перечислены среди системных
источников Wear OS в [документации Google](https://developer.android.com/reference/wear-os/wff/complication/default-provider-policy).
Остальные показатели могут зависеть от устройства, установленных приложений,
разрешений и наличия поставщика с поддерживаемым типом complication.
Новые поставщики в этой итерации не устанавливались и не создавались.

AUTO по-прежнему получает заголовок или значок от поставщика и выбран по
умолчанию. Ограничение в четыре символа относится к ручным вариантам,
не к исходному заголовку стороннего поставщика; длинный AUTO сокращается
по ширине ячейки. NONE скрывает только подпись, не значение.

## Сохранение старых настроек

Идентификаторы HI/LO, STEPS и EVENT не переименованы. Их текст при отображении
преобразуется в H/L, STEP и EVNT. Существующие настройки и выбранные поставщики
сохраняются при обновлении APK. Миниатюры и расшифровки показывают новые короткие
обозначения. [Все варианты](label-options.png).
