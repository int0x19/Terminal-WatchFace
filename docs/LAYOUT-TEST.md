# Тест разметок A/B/C — 0.4.0-test

Это сравнительная тестовая сборка, не выбор окончательного дизайна.
Установить APK поверх 0.3.0 с тем же ключом, затем удержать циферблат →
редактирование → «Тестовая разметка» → A, B или C.
Варианты имеют миниатюры настоящих разметок. Системный редактор может
располагать разделы в другом порядке, поэтому название важнее номера страницы.

| Вариант | Шапка | Нижняя таблица | Для чего сравнивать |
|---|---|---|---|
| A | Одна строка: UTC-время, смещение, значок батареи и процент | Подпись рядом со значением; часы 104, значения 32 | Крупное время и привычный терминальный стиль |
| B | Две увеличенные строки UTC / пояс и BATT / процент | Подпись 26, значения 36, больше ширины значению | Баланс привычной шапки и крупных данных |
| C | Компактная строка, как A | Подпись над значением; значения 36, длинные строки 28 | Данные с единицами и длинные показатели |

Размеры указаны в системе координат WFF 450×450. На часах они масштабируются.
Нижний ряд A/B сужен с учётом круглого экрана; для длинного SHORT_TEXT шрифт
там уменьшается. В C подписи остаются 26: выигрыш отдан крупным значениям,
а не одновременному увеличению всех букв. Это разные компромиссы для сравнения.

Во всех вариантах сохранены восемь независимых источников, прежние slotId,
28 коротких ручных подписей, AUTO/NONE, палитры, стили даты, секунды и 12/24 часа.
AUTO не переименовывает данные самостоятельно: заголовок UZTT от погодного
поставщика останется UZTT. Для температуры/диапазона можно выбрать TEMP/H/L
вручную; это не переключит сам источник.

## Как сравнить на часах

1. Выбрать одинаковые источники и подписи один раз. После этого менять только разметку.
2. Сравнить читаемость шагов, пульса, уведомлений и самого длинного показателя.
3. Проверить верхнюю строку, батарею 100%, крупное время, секунды и нижние углы круга.
4. Сравнить ambient и нажатия на все восемь полей.
5. Прислать снимки A/B/C или указать наиболее удобный вариант и оставшиеся неудобства.

## Проверка и воспроизведение

Девять регрессионных тестов проверяют все варианты, источники, идентификаторы,
доступные типы данных, непересекающиеся зоны выбора, центры нажатия и целостность
архива 0.3.0. XML валидируется как WFF 2, APK/AAB собираются, Android lint запускается.
Запуск существующего Wear OS AVD пока заблокирован нехваткой места: на разделе
доступно около 1.6 ГБ. Данные AVD и чужие файлы не удалялись. Реальный системный
редактор и рендеринг A/B/C на часах пока не подтверждены.

Генератор использует неизменяемый снимок `versions/0.3.0/watchface.xml`.
Для воспроизведения XML в отдельный файл:

```sh
python3 tools/build_layout_variants.py --output /tmp/terminal-layouts.xml
```

Применить полученную разметку к ресурсу WFF, затем:

```sh
python3 tools/rebuild_assets.py
sh tools/check.sh
python3 tools/archive_version.py
```

Сохранённая 0.3.0 не меняется; новая сборка и все шесть active/ambient-превью
архивируются отдельно в `versions/0.4.0-test/`.
